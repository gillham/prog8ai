# Prog8 AI context for developing user programs

This repository is extracted from the official Prog8 compiler repository and is adapted
to focus on writing user style programs with Prog8 and inline 6502 assembly.  The portion
dealing with the compiler itself (written in Kotlin) has been removed.

The files here are from the original GPLv3 licensed files here:
https://github.com/irmen/prog8

I've adapted them as a test case for AI work with Prog8 as a simplified standalone
repository without all of the baggage of the Prog8 compiler itself.
